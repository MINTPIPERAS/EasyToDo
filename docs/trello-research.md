# Trello 功能调研与对照表

> 用途：为 EasyToDo 提供功能参考，明确“借鉴哪些、简化哪些、不做哪些”。
> 版本：v1.0（个人本地版，不包含团队协作与登录体系）

---

## 一、Trello 核心概念

| 概念 | 说明 | EasyToDo 对应 |
|------|------|---------------|
| **Board（看板）** | 一个项目/主题的空间 | 一个“项目”或“便签板” |
| **List（列表）** | 看板中的竖列，代表阶段或分类 | 任务分组，如“待办 / 进行中 / 已完成” |
| **Card（卡片）** | 列表中的任务单元 | 一条待办/便签 |
| **Label（标签）** | 颜色标签，用于分类或优先级 | 标签/优先级 |
| **Due Date（截止日期）** | 卡片截止时间 | 任务截止日期 |
| **Checklist（检查清单）** | 卡片内子任务 | 子任务清单 |
| **Archive（归档）** | 不删除但隐藏 | 软删除/归档 |
| **Search / Filter** | 按关键词、标签、成员筛选 | 本地筛选与搜索 |

## 二、Trello 主要功能模块

### 2.1 看板（Board）

- 创建/重命名/删除看板
- 设置背景颜色/图片
- 收藏（Starred Boards）
- 最近访问
- 归档整个看板（Closed Boards）

**个人版简化：**
- 保留：创建、重命名、删除、收藏
- 舍弃：背景图片、团队共享、权限管理

### 2.2 列表（List）

- 添加新列表
- 重命名列表
- 拖动排序列表
- 归档列表
- 复制列表
- 一键归档列表内所有卡片

**个人版简化：**
- 保留：增删改、拖动排序、归档
- 舍弃：复制列表、批量归档（可后续加）

### 2.3 卡片（Card）

- 添加卡片
- 编辑标题/描述
- 拖动卡片到不同列表 / 同一列表内排序
- 设置标签、截止日期、封面
- 添加检查清单（Checklist）
- 添加附件（图片/文件）
- 评论与活动记录
- 归档卡片

**个人版简化：**
- 保留：标题、描述、标签、截止日期、检查清单、归档
- 舍弃：附件、评论、活动记录、封面（可用标签色替代）

### 2.4 标签与筛选

- 多色标签
- 按标签筛选卡片
- 按关键词搜索卡片

**个人版：** 全部保留，使用 Element Plus 的 `el-tag` / `el-check-tag`。

### 2.5 搜索与筛选

- 顶部搜索框
- 按列表、标签、关键词过滤

**个人版：** 保留关键词搜索 + 标签筛选。

## 四、UI / UX 参考

### 4.1 布局

- 顶部固定导航栏：Logo + 搜索 + 看板切换
- 横向滚动看板区域
- 列表纵向排列卡片
- 卡片详情使用抽屉或弹窗展示

### 4.2 交互

- 拖拽排序为主
- 点击卡片展开详情
- 右键/更多按钮触发列表菜单
- 搜索实时过滤

### 4.3 视觉

- 简洁白色/浅灰背景
- 卡片白色圆角阴影
- 标签为小色块
- 列表顶部有标题 + 操作按钮

## 五、Element Plus 组件映射建议

| Trello 元素 | 推荐 Element Plus 组件 |
|-------------|------------------------|
| 顶部导航 | `el-header` + `el-menu` / `el-input` |
| 看板横向滚动区 | 自定义 flex 容器 |
| 列表卡片 | `el-card` |
| 列表标题输入 | `el-input` |
| 添加按钮 | `el-button` + `el-icon` |
| 标签 | `el-tag` / `el-check-tag` |
| 卡片详情弹窗 | `el-dialog` / `el-drawer` |
| 日期选择 | `el-date-picker` |
| 颜色选择 | `el-color-picker` |
| 下拉菜单 | `el-dropdown` |
| 消息提示 | `el-message` / `el-notification` |
| 确认删除 | `el-popconfirm` |
| 空状态 | `el-empty` |
| 加载状态 | `el-loading` |
| 抽屉设置 | `el-drawer` |

> 原则：能用 Element Plus 组件解决的问题，不自行封装组件。
