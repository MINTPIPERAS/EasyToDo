# 方案：主题自定义功能（按钮主色 + 页面背景：纯色/图片）

## 总体思路

不引入新依赖，采用「CSS 变量 + Element Plus 主题变量覆盖 + localStorage(偏好) + IndexedDB(图片)」：

- 按钮颜色：运行时覆盖 `--el-color-primary` 及派生色阶（light-3/5/7/8/9、dark-2），全局所有 type="primary" 按钮整体换色，组件零改动
- 页面背景：支持纯色（预设+取色器）与图片（上传 jpg/png/svg）两种模式，CSS 变量驱动，实时切换

## 1. 数据与持久化（分层存储）
- 主题偏好（主色、背景类型 bgType、背景色、填充方式）→ localStorage（key: easytodo-settings），main.js 中 app.mount() 前同步读取应用，刷新不闪默认色
- 背景图片 Blob → 独立小库 `EasyToDoSettingsDB`（新文件 `src/db/settingsDB.js`，key-value 存 bgImage），不动现有 EasyToDoDB，不影响导出/导入/重置逻辑

## 2. 新增 `src/utils/theme.js`（主题应用）
`applyTheme()` 用 document.documentElement.style.setProperty 设置：
- `--el-color-primary` 及派生色阶（hex 混色函数派生，不引第三方库）
- `--app-primary-text`：亮度检测，主色过浅时按钮文字自动切深色
- 纯色模式：`--app-page-bg` + `--app-list-bg`（列表栏联动提亮色）
- 图片模式：`--app-page-bg-image: url(blobURL)` + 填充方式变量；列表栏自动变半透明白+背景模糊（毛玻璃），卡片保持白色保证可读

背景图处理：
- 上传转 Blob 存 IndexedDB，启动异步加载生成 objectURL 应用
- jpg/png 超过最长边 2560px 自动 canvas 等比压缩；SVG 原样存储
- 更换/清除时释放旧 objectURL 和 Blob

## 3. 样式改造（硬编码 → CSS 变量）
- style.css：:root 变量默认值；.el-button--primary 文字色覆盖
- App.vue：.app-container 背景改为变量组合（color+image+size/position/repeat）
- TaskList.vue：.task-list 背景 → 变量
- AppHeader.vue：Logo 图标硬编码 #409EFF → 跟随主题色

## 4. 设置界面（SettingsDialog.vue + AppHeader 入口）
- AppHeader 右侧「设置」按钮（齿轮图标）
- 按钮主题色：8 色预设色板 + 自由取色器
- 页面背景：「纯色 / 图片」分段切换
  - 纯色：7 色预设 + 取色器
  - 图片：上传（限 jpg/png/svg）、缩略图预览、填充方式（填满/居中/平铺）、清除图片
- 更改实时生效，关闭即保留；另有「恢复默认」

## 文件清单
新增 4 个：settingsStore.js、theme.js、settingsDB.js、SettingsDialog.vue
修改 5 个：main.js、style.css、App.vue、AppHeader.vue、TaskList.vue

## 验收
- npm run build 通过
- 主色切换后所有 primary 按钮及 Logo 图标变色，hover 正常，过浅主色文字仍可读
- 纯色/图片背景切换生效，列表栏联动，刷新后保持
- 恢复默认回到原始配色
